# Studio fonts

Variable WOFF2 fonts sourced from the official Google Fonts CSS API on October 1,
2026. Each family is licensed under the included SIL Open Font License.

Source request:
https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..600&family=Fraunces:opsz,wght@9..144,400..500&family=Space+Grotesk:wght@400..700&display=swap

- studio-0 and studio-1: DM Sans, Latin Extended and Latin.
- studio-2 through studio-4: Fraunces, Vietnamese, Latin Extended, and Latin.
- studio-5 through studio-7: Space Grotesk, Vietnamese, Latin Extended, and Latin.

The subsets load only for their declared Unicode ranges in ../fonts.css.
